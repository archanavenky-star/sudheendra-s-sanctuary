# Project Decisions

- Keep all published writings as static typed content in the client bundle because the site intentionally has no data capture or backend.
- Use shared layout and emblem components for the masthead, footer landscape, and content symbols so every page keeps one contemplative visual language.
- Use a desktop-first 1440px editorial grid for discovery and page headers, while preserving a narrower measure only for long-form body text, because the publication should feel expansive without sacrificing readability.
- Keep alternate home-page concepts on separate routes during review, because visual directions should be compared without replacing the approved current home page.
- Treat Insights as untitled text blocks in an in-page master-detail reader, because readers should browse every opening without leaving the collection.
